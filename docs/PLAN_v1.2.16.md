# План и проверка v1.2.16

## Статус

GEARMASS и весь план **не завершены**. Третий шаг этапа 8: статусные биты FXTRACT и FSCALE в runtime x87. APK и полная игра не собирались; ARM, телефон и поведение под нагрузкой не проверены. Улучшение FPS не обещается. Для отката сохраните работающую v1.2.3.

## Что изменено

Сверка с аппаратным x87 на специальных операндах (±0, субнормальные, максимальные, ±inf, ±NaN, большие и дробные масштабы) при заранее выставленных C-битах показала:
- **FXAM** совпадает с аппаратным по классу, знаку и TOP.
- **FXTRACT** и **FSCALE** не сбрасывали C1. Теперь сбрасывают.
- **FSCALE** не ставил флаги исключений. Теперь по правилам аппаратного 80-битного формата: OE|PE при порядке результата больше 16383 (C1=1 при округлении вверх с учётом режима гостя); UE|PE, когда результат не представим точно денормалом 80-битного формата (не кратен 2^-16445); бесконечный масштаб флагов не даёт. Флаги определяются по показателю, поэтому для значений, которые double хранит как inf или 0, но которые на x87 конечны, флаги не ставятся.

Значения остаются в double: FSCALE(1, 2000) даёт inf (на x87 конечное число), эта проблема 80-битного представления не решена.

Изменён только `runtime/rt_fp.c`, не `rt.h`, не генератор и не `out/`: перегенерация и полная перекомпиляция игровых C-файлов не требуются, нужна пересборка runtime.

## Проверки

Аппаратный x86-64, gcc 13.3, исключения маскированы:
- Новый `tests/recomp/test_fpu_misc_native.c`, 7 402 проверки: прежний runtime **5 122 расхождения**, теперь **0** при `-O1`, `-O2`, `-O3` и под UBSan (`-O1`).
- Прежние тесты: FRNDINT 65 938/0, FIST 100 512/0, FSCALE 10 289/0, FPREM 40 022/0, FPREM на специальных операндах 3 888/0.
- Тесты на Python (capstone, keystone, unicorn), GEARMASS, Vulkan и Android Java в этой версии не запускались.

Ограничения: DE не сравнивается (его на железе ставит загрузка субнормального double, runtime DE не моделирует); значения в граничном наборе FSCALE не сравниваются; знак NaN при FPREM не учитывается; представление остаётся double. Флаги при незамаскированных исключениях не эмулируются.

```sh
gcc -O2 -fwrapv -fno-strict-aliasing -ffunction-sections -Wl,--gc-sections -Iruntime tests/recomp/test_fpu_misc_native.c runtime/rt_fp.c -lm -o /tmp/t && /tmp/t
```

## Осталось

- Этап 8: 80-битная арифметика и полная эмуляция исключений x87 не реализованы. Флаги инструкций, сгенерированных встроенно (FYL2X, F2XM1, FPATAN, FSQRT и др.; не в `rt_fp.c`), не сверены; расхождения вокруг кратных π, DE, экспериментальная тригонометрия, локальные регистры, TSO, Android PGO и нативные замены требуют проверки и измерений; внедрение в генерацию требует долгой сборки.
- Vulkan: настоящая упреждающая компиляция будущих pipeline не реализована; secondary buffers и восстановление остаются экспериментальными и не проверены на Mali.
- Длительная проверка GEARMASS AUTO, датчиков, авторазрешения, FPS, нагрева, батареи и стабильности на телефоне; оценить пользу распараллеливания mip-карт и конвертации данных.
