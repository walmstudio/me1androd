# План и проверка v1.2.8

## Статус

GEARMASS и весь план порта **ещё не завершены**. Это промежуточные исходники: APK и полная игра не собирались, устройство Mali не проверялось. Для отката сохраните известную рабочую v1.2.3. Повышение FPS не гарантируется.

## Достоверность авторазрешения

Опция авторазрешения между сеансами по-прежнему выключена по умолчанию. Ранее запись хранила только последний лимит FPS: если он менялся в течение сеанса, усреднённый FPS мог ошибочно использоваться для решения при другом лимите. Теперь во время кадров сохраняется исходный лимит и факт любого изменения, включая возвращение к старому значению и переход из режима без лимита. В файле записывается `fps_limit_mixed`; при изменении лимита запись не используется авторазрешением. Старые записи, где отсутствует этот признак, тоже пропускаются: первый новый сеанс создаст совместимые данные.

Для повышения разрешения GEARMASS теперь требует два подходящих учтённых сеанса с достаточным FPS, максимумом измеренного нагрева ниже 80 % и доступным измерением запаса по нагреву не менее чем в 95 % активного времени каждого сеанса. Доля — оценка по периодическим измерениям, не непрерывная запись температуры. Отсутствие данных, например если система предоставляет только thermal status без headroom или подходящих датчиков нет, блокирует автоматическое повышение; можно установить разрешение вручную. Автоматическое понижение по данным GPU не требует тепловых данных. Остальные условия v1.2.3 (включая 180 секунд активных сцен, совпадение разрешения и лимита, один учёт run_id и пользовательский потолок) сохранены.

Файл статистики теперь содержит `active_heat_known` и `fps_limit_mixed`. В момент сохранения сведения об исходном и текущем лимитах сравниваются консервативно; последняя запись лимита читается атомарно. Данные могут оставаться неполными после аварийного завершения: запись периодическая, раз в 30 секунд. При запуске из разных процессов одновременно работа авторазрешения и разрешение конфликтов настроек специально не проверялись.

## Проверки

- `build/test_gm`: **249/0** — в том числе формат стабильного и изменённого лимита в записи.
- `build/test_gm_resolution`: **33/0** — прежние условия, старые и недопустимые записи, изменение лимита, отсутствующие показания, 94,9 % и 95 % покрытия; сквозной тест также проверяет 94,99 %.
- `build/test_gm_integration`: **15/0** — искусственный сеанс через реальный writer и reader, понижение, повышение после двух подходящих сеансов, неполный/неизвестный нагрев, смена лимита и отсутствие кадров.
- `build/test_gm_thermal`: **11/0**. Тесты авторазрешения и сквозной тест также прошли с UBSan. Java-исходники Android проверены javac; APK и полная игра не собраны.
- Программный Vulkan Mesa lavapipe: `test_cmd` 430/0, сценарии secondary и 12 одинаковых кадров; восстановление DEVICE_LOST — 26 синтетических сценариев по 56/0, ноль сообщений Vulkan validation. Реальную потерю устройства и драйвер Mali они не воспроизводят.
