# Примечания к релизу: v1.2.18

Здесь собраны все изменения от **v1.2.1** до **v1.2.18** порта статической перекомпиляции Mass Effect (2007) для Android и Linux.

## Что нового в v1.2.18
- **Режим экрана (растягивание на весь экран)**: добавлена настройка `port.stretch_mode` с тремя режимами:
  - **По размеру (Fit)** — сохранение пропорций 16:9 с чёрными полосами (letterbox).
  - **Растянуть (Stretch)** — заполнение всего экрана без сохранения пропорций.
  - **Заполнить (Fill)** — масштабирование на весь экран с обрезкой краёв без искажения картинки.
- Настройка доступна в UI лаунчера Android и передаётся в игру через переменную окружения `ME1_STRETCH_MODE`.
- Оба пути рендеринга (GLES и Vulkan) теперь поддерживают динамический расчёт Viewport в зависимости от выбранного режима.

## Изменения от v1.2.1 до v1.2.18

### v1.2.18 — Режим экрана (растягивание на весь экран)
- Добавлена настройка `port.stretch_mode` (Fit / Stretch / Fill) в `settings/me1settings.c`.
- Обновлён `MainActivity.java`: добавлен Spinner для выбора режима растягивания.
- Реализован динамический расчёт Viewport в `hle_d3d9_gl.h` и `hle_d3d9_vk.h`.

### v1.2.17 — Аудит встроенных x87-инструкций (этап 8, шаг 4)
- Новый `tests/recomp/audit_x87_inline_native.py`: проверяет x87-инструкции на аппаратном x87.
- Результат: все значения совпадают, кроме FPTAN при ±inf/NaN и FSIN/FCOS/FSINCOS/FPTAN для |x| ≥ 2^63.
- Android versionCode 55, Linux 1.2.17.

### v1.2.16 — C1 и флаги исключений FXTRACT/FSCALE (этап 8, шаг 3)
- `rt_fxtract` и `rt_fscale` теперь сбрасывают C1 (раньше оставался старый бит).
- `rt_fscale` ставит OE|PE и C1 при переполнении, UE|PE (с C1 при округлении вверх) при неточном денормале/нуле по 80-битному диапазону.
- Новый `tests/recomp/test_fpu_misc_native.c`: 0/7402 расхождений после исправления.
- Android versionCode 54, Linux 1.2.16.

### v1.2.15 — Биты состояния FPREM/FPREM1 (этап 8, шаг 2)
- `rt_fprem` теперь сбрасывает C1 и C2 при NaN-операнде и недопустимой операции; ставит C2 при частичной редукции.
- Новый `tests/recomp/test_fprem_special_native.c`: 0/3888 расхождений после исправления.
- Android versionCode 53, Linux 1.2.15.

### v1.2.14 — FRNDINT не зависит от режима округления хоста (этап 8, шаг 1)
- `rt_round_fcw` больше не вызывает `floor()`/`ceil()`; используется `trunc` с точной поправкой ±1.
- Исправляет знак нуля при floor(+0.1) в режиме FE_DOWNWARD.
- Android versionCode 52, Linux 1.2.14.

### v1.2.13 — Неполные данные тепловых датчиков GEARMASS
- Пропажа или некорректное значение хотя бы одного датчика больше не считается полным охлаждением.
- Существующий тепловой предел не снимается при неполных показаниях; анизотропия не повышается.
- В файл сеанса добавлено `thermal_partial_seconds`.
- Android versionCode 51, Linux 1.2.13.

### v1.2.12 — Флаги FRNDINT и аппаратный аудит x87
- FRNDINT теперь обновляет sticky-флаг precision и C1 (увеличение модуля при округлении).
- Добавлен воспроизводимый `tests/recomp/audit_x87t_native.py`.
- Android versionCode 50, Linux 1.2.12.

### v1.2.11 — Исправления округления x87/SSE и FSCALE
- Исправлено округление nearest-even в `rt_frnd` и `rt_cvt_f2i32`.
- Исправлены случаи FSCALE (±0 при +∞ масштабе и ±∞ при −∞ масштабе).
- Android versionCode 49, Linux 1.2.11.

### v1.2.10 — Экспериментальная корректность x87-тригонометрии
- Отдельный opt-in генератор исправляет FSIN/FCOS/FSINCOS/FPTAN на конечных значениях с |x| ≥ 2⁶³.
- FPTAN правильно помещает NaN при NaN-входе.
- Android versionCode 48, Linux 1.2.10.

### v1.2.9 — Экспериментальное перекрытие подготовки Vulkan
- Добавлен `ME1_VK_ASYNC_PIPE=2`: создание pipeline текущего draw в рабочем потоке совмещается с подготовкой индексов, текстур и констант.
- `ME1_VK_PIPEIDLE=1` имеет приоритет.
- Android versionCode 47, Linux 1.2.9.

### v1.2.8 — Достоверность данных авторазрешения
- Статистика GEARMASS отмечает изменение лимита FPS в пределах сеанса.
- Для автоматического повышения разрешения нужны данные о запасе по нагреву ≥ 95% активного игрового времени и максимум ниже 80%.
- Android versionCode 46, Linux 1.2.8.

### v1.2.7 — Тепловая политика GEARMASS AUTO
- Исправлен конфликт: после смены сцен защита от колебаний могла на один цикл поднять уровень выше теплового ограничения.
- Тепловой предел имеет приоритет; прерванная сменой сцены или тепловым пределом проверка FPS не записывается как неудачный шаг.
- Android versionCode 45, Linux 1.2.7.

### v1.2.6 — Экспериментальное восстановление Vulkan
- Исправлен путь восстановления после DEVICE_LOST: игра получает корректные статусы и может вызвать Reset.
- При восстановлении исправлено освобождение ресурсов Vulkan, сохраняются переведённые шейдеры.
- Android versionCode 44, Linux 1.2.6.

### v1.2.5 — Экспериментальная параллельная запись Vulkan
- Реализован эксперимент `ME1_VK_SECONDARY=1`: снимки состояния draw объединяются в пакеты до 64; части пакета записываются в отдельные вторичные command buffers.
- Android versionCode 43, Linux 1.2.5.

### v1.2.4 — x87 и экспериментальные инструменты оптимизации
- Исправлен `FPREM`/`FPREM1` в рантайме: при разнице экспонент ≥ 64 применяется частичное сокращение с C2=1.
- Новый `tools/recomp_local.py`: экспериментальный перекомпилятор для групп регистровых инструкций.
- Linux GCC PGO: `tools/pgo-linux.sh train` и `use`.
- Android versionCode 42, Linux 1.2.4.

### v1.2.3 — Авторазрешение и экспериментальный Vulkan

- Эксперимент `ME1_VK_ASYNC_PIPE=1`: создание pipeline в отдельном потоке совмещается с подготовкой констант текущего draw.
